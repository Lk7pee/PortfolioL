# Prévias dos projetos

Capturas reais realizadas em 17/11/2026, usando Chrome em viewport desktop de 1440 × 960 px. As imagens foram redimensionadas para 1200 × 800 e convertidas para WebP (qualidade 82), sem alterar o conteúdo dos sites. Não são mockups ou imagens geradas.

| Arquivo | Origem | Tamanho |
| --- | --- | --- |
| `registral-abreu-lima.webp` | https://cartorioregistralabreuelima.com/ | 66.888 bytes |

| `sao-jose-belmonte.webp` | https://cartoriosjbelmontepe.com/ | 71.442 bytes |
| `rcpn-abreu-lima.webp` | https://registrocivilabreuelima.com/ | 49.740 bytes |

As quatro páginas responderam HTTP 200 durante a captura. A aparência dos sites pode mudar após essa data.

Para atualizar: capture a página real com a mesma proporção 3:2, converta para WebP e substitua o arquivo. Ajuste `imageAlt` em `js/script.js` se o conteúdo visual mudar e execute `node tools/sync-projects.cjs` na raiz. Se não houver captura, deixe `image` vazio no objeto do projeto para usar uma apresentação textual.
