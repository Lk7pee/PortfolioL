# Portfólio — Filipe Gualberto

Portfólio pessoal e profissional de Filipe Gualberto, desenvolvido para apresentar serviços de criação de sites institucionais, sites para cartórios, portfólios e sistemas simples.

A identidade visual segue uma direção editorial e autoral, inspirada em cartazes, impressos e estúdios criativos: contraste forte, tipografia expressiva, blocos gráficos e pequenos elementos artesanais. O site possui modo escuro como experiência principal, com reconhecimento da preferência do sistema e alternância manual.

## Tecnologias

- HTML5 semântico
- CSS3 mobile-first
- JavaScript puro
- Tema escuro/claro com preferência salva no navegador
- SVG inline
- Intersection Observer

Não há frameworks, bibliotecas externas, backend ou banco de dados obrigatório.

## Como abrir

Não é necessário instalar nada. Abra o arquivo `index.html` em qualquer navegador moderno.

Um servidor local, como Live Server, pode ser usado durante o desenvolvimento, mas é opcional.

## Publicação no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie o conteúdo da pasta `portfolio-filipe` para a raiz do repositório.
3. Abra **Settings > Pages**.
4. Escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`.
6. Salve e aguarde a publicação.

Os caminhos de CSS e JavaScript são relativos, então o projeto funciona tanto em repositório de usuário quanto em repositório de projeto.

## Personalização

- Paleta, tema escuro/claro e estilos globais: início de `css/style.css`
